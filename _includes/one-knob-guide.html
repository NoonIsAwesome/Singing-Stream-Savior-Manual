How One Knob worksQuick control without hiding the real parameters

Supported effects offer a One Knob Simple view. Choose a starting point first, then use the central knob to move several related parameters together toward a lighter or stronger result. At 50%, the selected starting point is reproduced exactly; the endpoints are effect-specific safe ranges, not a universal Dry/Maximum scale.

One Knob and Advanced mode edit the same effect. Switching views alone never changes the sound or adds a second processing stage. Use One Knob for a fast live-singing adjustment, then open Advanced when one parameter—such as Threshold, Release, Wet, or Tone—needs separate control. Effects whose job is already a direct adjustment, such as Input Gain and EQ, show their direct controls instead of inventing an extra macro.

{% when 'zh-CN' %}
One Knob 的工作方式快速调整，同时保留完整参数

支持的效果器会提供 One Knob 简易界面。先选择一个起始设定，再用中央旋钮让数个相关参数一起朝较轻或较强的结果变化。50% 会准确还原所选起始设定；0% 与 100% 是该效果器专属的安全范围，并不统一代表全干声与最大效果。

One Knob 与进阶模式编辑的是同一颗效果器；只切换界面不会改变声音，也不会多加一层处理。现场演唱时可先用 One Knob 快速调整；若 Threshold、Release、Wet 或 Tone 等参数需要分开控制，再进入进阶模式。Input Gain、EQ 这类本身就是直接调节的效果器，会直接显示实际参数，不会额外制造一个宏旋钮。

{% when 'ja' %}
One Knob の仕組み実パラメーターを残したまま素早く調整

対応エフェクトには One Knob の簡易画面があります。最初に開始設定を選び、中央ノブで複数の関連パラメーターをまとめて弱め／強めへ動かします。50% は選択した開始設定を正確に再現します。0% と 100% はエフェクトごとに設計された安全な範囲であり、共通の Dry／最大値を意味しません。

One Knob と詳細モードは同じエフェクトを編集します。表示を切り替えるだけでは音も処理段数も変わりません。ライブでは One Knob で素早く整え、Threshold、Release、Wet、Tone などを個別に詰めたい場合だけ詳細モードを使います。Input Gain や EQ のように操作自体が直接的なエフェクトは、不要なマクロを追加せず実パラメーターを表示します。
