歌曲列表显示

传统列表仍是默认值；想更快辨认歌曲时，可在“设置 → 一般 → 歌曲列表显示”改用卡片列表。卡片会突出显示歌名，同时保留来源、封面与歌词状态；双击仍会播放，铅笔图标则用于编辑显示歌名。

{% when 'ja' %}

曲リストの表示

初期設定は従来の表形式です。より見やすくしたい場合は「設定 → 一般 → 曲リスト表示」でカード表示へ切り替えられます。表示曲名を大きく見せつつ、音源、ジャケット、歌詞の状態も確認できます。ダブルクリックは再生、鉛筆アイコンは表示曲名の編集です。

{% when 'ko' %}

곡 목록 표시

기본값은 기존 표 형식입니다. 곡을 더 빠르게 찾고 싶다면 “설정 → 일반 → 곡 목록 표시”에서 카드 표시로 바꿀 수 있습니다. 표시 곡명을 강조하면서 음원, 커버와 가사 상태를 유지하며, 두 번 클릭은 재생, 연필 아이콘은 표시 곡명 편집입니다.

{% when 'en' %}

Song list display

The traditional table remains the default. Choose Card list under Settings → General → Song List Display when you want titles to be easier to scan. Cards keep the source, cover, and lyrics indicators; double-click still plays the song, while the pencil icon edits its Display title.

{% else %}

歌曲列表顯示

傳統列表仍是預設值；想更快辨認歌曲時，可在「設定 → 一般 → 歌曲列表顯示」改用卡片列表。卡片會突出顯示歌名，同時保留來源、封面與歌詞狀態；雙擊仍會播放，鉛筆圖示則用來編輯顯示歌名。

{% case locale %} {% when 'zh-CN' %}

BGM 播放列表

展开“背景音乐”的列表按钮后，可保存多首本地音频或 YouTube 音源，为每首 BGM 添加备注，并直接拖动调整顺序。正在播放的项目会清楚高亮；YouTube 播放列表也可选择只加入当前视频或一次导入全部项目。

  • 单曲循环（默认）：持续播放目前选择的 BGM。
  • 全部循环：按列表顺序播放，结束后从第一首继续。
  • 全部随机循环：从列表中随机选择下一首。
{% when 'ja' %}

BGM プレイリスト

「背景音楽」のリストボタンを開くと、ローカル音源や YouTube 音源を複数保存し、各 BGM にメモを付け、ドラッグで順番を変更できます。再生中の項目は強調表示されます。YouTube プレイリストは現在の動画だけ、または全項目をまとめて追加できます。

  • 1曲リピート（初期設定）：選択中の BGM を繰り返します。
  • 全曲リピート：リスト順に再生し、最後の曲から先頭へ戻ります。
  • シャッフルリピート：次の BGM をリストからランダムに選びます。
{% when 'ko' %}

BGM 재생목록

“배경 음악”의 목록 버튼을 열면 로컬 음원과 YouTube 음원을 여러 개 저장하고, 각 BGM에 메모를 붙이며, 드래그로 순서를 바꿀 수 있습니다. 재생 중인 항목은 명확하게 강조됩니다. YouTube 재생목록은 현재 영상만 또는 모든 항목을 한 번에 추가할 수 있습니다.

  • 한 곡 반복(기본값): 선택한 BGM을 계속 반복합니다.
  • 전체 반복: 목록 순서대로 재생한 뒤 처음으로 돌아갑니다.
  • 전체 무작위 반복: 목록에서 다음 BGM을 무작위로 선택합니다.
{% when 'en' %}

BGM playlist

Open the list button in Background Music to keep multiple local or YouTube sources, add a note to each BGM, and drag items into order. The active track is clearly highlighted. A YouTube playlist can add either the current video or every item at once.

  • Repeat one (default): keep the selected BGM looping.
  • Repeat all: play in list order and continue from the beginning.
  • Shuffle all: choose each next BGM randomly from the list.
{% else %}

BGM 播放清單

展開「背景音樂」的清單按鈕後，可保存多首本機音檔或 YouTube 音源，替每首 BGM 加上備註，並直接拖曳調整順序。正在播放的項目會清楚高亮；YouTube 播放清單也能選擇只加入目前影片，或一次匯入全部項目。

  • 單曲循環（預設）：持續播放目前選擇的 BGM。
  • 全部循環：依清單順序播放，最後一首結束後回到第一首。
  • 全部隨機循環：每次從清單隨機選擇下一首 BGM。
