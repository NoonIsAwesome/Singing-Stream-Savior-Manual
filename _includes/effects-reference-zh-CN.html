输入增益 Input Gain校准进入 Profile 的信号电平

位于整条效果链最前端，用于调整软件内部工作电平，不能代替录音接口的硬件 Gain。

直播演唱建议硬件 Gain 调好后先保持接近 0 dB，再用最轻与最响的段落测试，并为 EQ 与压缩保留余量。

注意事项无法修复进入软件前已经削波的信号；过高会让后续效果过载并改变 Noise Gate 的判断。

  • 输入增益：提高或降低整条 Profile 的输入。
背景噪声衰减在人声空隙降低持续底噪

以平滑的向下扩展降低风扇、空调与房间底噪，不会像完全关闭麦克风那样突兀。

直播演唱建议先确认气声与弱音尾部仍然自然，再逐步增加最大衰减；通常放在 Gate 前作温和清理。

注意事项无法分离与歌声同时出现的噪声。阈值过高或关闭过快会产生抽动并吃掉弱音。

  • 最大衰减／阈值：衰减深度与开始判断的电平。
  • 开启／关闭速度：恢复与淡出的速度。
噪声门 Noise Gate在句子之间关闭麦克风

开启与关闭采用不同阈值，避免电平在边界附近时反复跳动。

直播演唱建议先测量房间底噪，再用气声字头、辅音与长尾音试唱。适度增加 Hold 与 Release 往往比直接提高阈值自然。

注意事项无法移除演唱同时发生的键盘声；设置过紧会切掉换气与尾音。Detector HPF 只改变判断，不会滤掉实际人声。

  • 开启／关闭阈值：进入与离开开启状态。
  • Attack／Hold／Release：打开、保持与关闭形状。
  • 关闭衰减／Detector HPF：关闭深度与低频检测过滤。
压缩器 Compressor缩小轻声与强声的差距

超过 Threshold 后按 Ratio 减少继续增加的电平，再以 Makeup 补回所需输出。

直播演唱建议让普通歌唱峰值产生适量且会恢复的增益衰减，保留字头，并在等响条件下比较 Bypass。

注意事项Attack 太快会削弱咬字，Release 太短会抽动，Makeup 过多会把底噪一起放大。

  • Threshold／Ratio：开始位置与压缩强度。
  • Attack／Release：响应与恢复时间。
  • Makeup／Knee：补偿增益与转折宽度。
均衡器 Equalizer（EQ）去除多余频率并让人声在伴奏中突出

六个频段提供 Low Cut、Shelf、Bell 与 High Cut，可拖动或输入精确数值。

直播演唱建议先切除无用超低频，再以宽而小的调整减少混浊、增加少量存在感，而不是只提高人声音量。

注意事项高 Q 大幅提升容易放大共振与啸叫；固定的男女声频率表不能取代对歌手、麦克风和房间的实际试听。

  • 类型／频率：滤波形状与目标范围。
  • 增益／Q：调整量与带宽。
  • 频段 Bypass：单独比较一个频段。
饱和 Saturation增加泛音、密度或刻意的粗糙感

Warm Vocal、Rock Edge 与 Metal Bite 从温和密度逐步过渡到明显的非线性质感。

直播演唱建议普通演唱先用低 Drive、低 Mix；摇滚或嘶吼段落再逐步提高，并用 Output Trim 进行等响比较。

注意事项更响很容易被误判为更好。过量会放大齿音和底噪、模糊辅音并消耗 Limiter 余量。

  • 类型／Drive／Color：曲线、强度与个性。
  • Mix／Output Trim：干湿比例与输出匹配。
Air 感增强增加存在感、呼吸感与高频光泽

Mid Air 主要提高人声存在感，High Air 增加更高频的呼吸与光泽。

直播演唱建议先用少量 Mid Air 提高歌词清晰度，再保守加入 High Air；配合 De-esser 通常比大幅提升高频自然。

注意事项它也会暴露嘶声、房间噪声与齿音；请先用 Output Trim 匹配音量再判断。

  • Mid Air／High Air：存在感与高频光泽。
  • Output Trim：匹配 Bypass 音量。
齿音抑制器 De-esser压低刺耳的 S、SH 等辅音

只有所选高频区域变得突出时才短暂衰减，不是把整条人声永久变暗。

直播演唱建议用容易触发齿音的歌词试唱，调到刺耳感下降但辅音仍清楚；放在 Air 或明亮 EQ 后可捕捉新增齿音。

注意事项Threshold 太低或最大衰减太大会造成含糊；正确频率取决于歌手和麦克风。

  • 频率／Threshold：检测区域与灵敏度。
  • 最大衰减／Attack／Release：限制与响应时间。
变声器 Voice Changer调整 Pitch 与 Formant 制作角色效果

可在改变音高的同时调整声道大小感，减少单纯移调造成的卡通感。

直播演唱建议先从小幅半音与 Formant 调整开始，或用 Mix 混回原声；选择接近演唱者的人声范围可帮助分析。

注意事项大幅移调会产生明显处理痕迹并可能增加 Profile latency；它不是匿名或身份保护工具。

  • Pitch／Formant：音高与声道大小感。
  • Mix／人声范围：干湿比例与分析辅助。
和声器 Harmony（实验性）按歌曲调性生成辅助声部

依据歌曲 Key／调式与主唱音高生成自然音阶三度或八度；跟踪信心不足时会淡出。

直播演唱建议先确认歌曲 Key，以低 Mix 点缀副歌或长音；用 Tone、Width 与 Humanize 将和声放在主唱后方。

注意事项Key 错误、滑音、嘶吼或音高不稳可能导致跟踪失准；实验性和声不应盖过主唱。

  • 方向：上／下三度或高／低八度。
  • Mix／Width：电平与立体声宽度。
  • Humanize／Tone／Tracking：变化、明暗与信心门槛。
叠声器 Doubler建立双轨人声的厚度与宽度

以两层轻微错时、偏移音高的人声模拟重唱，而不是明显的节奏回声。

直播演唱建议主歌使用较低 Mix，副歌再通过 Switch 加宽；短 Delay、轻微 Detune 与中等 Width 通常最自然。

注意事项Delay 或 Mix 过大会模糊辅音，过宽在 Mono 中可能变薄；直播前应同时检查立体声与 Mono。

  • Mix／Delay／Detune：电平、时间差与 cents 偏移。
  • Width／Humanize／Tone：宽度、变化与明暗。
Delay加入 slap、KTV 或节奏回声

直接人声保持原位，Time 决定重复间隔；短时间形成 slap，长时间产生清楚回声。

直播演唱建议按歌曲速度选择 Time，用 Low／High Cut 让回声比主唱更薄、更暗，并保持保守的 Wet 与 Feedback。

注意事项Feedback 过高会长时间累积甚至接近失控；同一毫秒值不会在所有歌曲速度中都落在拍点。

  • Wet／Time／Feedback：回声电平、间隔与重复量。
  • Width／Low Cut／High Cut：左右展开与频率整理。
Reverb建立房间、Plate 或较长空间感

密集反射建立深度；Pre-delay 分开主唱与尾音，Size、Decay、Damping 决定空间特性。

直播演唱建议先用 Pre-delay 保留咬字，再调 Decay 与 Wet。聊天 Profile 使用短而少的空间，空灵风格可以更长但主唱仍应靠前。

注意事项真实房间已经很响时再加长 Reverb 会失去清晰度；Wet 与 Decay 过高会遮住下一句。

  • Wet／Pre-delay：比例与开始时间。
  • Size／Decay／Damping：空间大小、尾音与明暗。
Shimmer在混响尾音加入高八度光晕

将尾音上移一个八度并回授；Ducking 可在主唱出现时压低光晕，在句子空隙再浮现。

直播演唱建议从低 Wet、受控 Feedback、较暗 Tone 与足够 Ducking 开始；保存 Profile 默认状态后，再用全局 Switch 切换副歌。

注意事项明亮尾音很容易累积。Block Bypass、Profile 默认开关与当前歌曲的临时 Switch 是三种不同状态。

  • Wet／Pre-delay／Decay：电平、开始与尾音。
  • Feedback／Tone／Ducking：累积、明暗与主唱避让。
限制器 Limiter在 Profile 输出拦截偶发峰值

Profile Limiter 与 Output Final Limiter 都是立体声联动、带 Lookahead 的 Sample-Peak Limiter，并非 True-Peak Limiter。Lookahead 只预读采样点峰值，不会重建采样点之间的峰值。

直播演唱建议将 Profile Limiter 用作偶发峰值保护，不要整首持续重压；正式 Mix 另有 Final Limiter，其默认 −1.0 dBFS ceiling 提供编码前余量。

注意事项−1.0 dBFS Sample Peak 不保证 AAC、重采样或波形重建后仍低于 −1.0 dBTP。需要 dBTP 标准时应使用具 True Peak 能力的后级工具。

  • Input Gain／Ceiling：推动量与采样点上限。
  • Release：峰值后的恢复速度。
  • Lookahead：增加延迟的预读，不等于 True Peak。
