入力ゲインProfile に入るレベルを整える

チェーン先頭の内部動作レベルを調整します。オーディオインターフェースのプリアンプ Gain の代わりではありません。

歌配信での目安ハードウェア Gain を決めた後は 0 dB 付近から始め、最も小さい／大きいパートを歌って EQ と Compressor の余裕を残します。

注意点アプリに入る前のクリップは修復できません。上げすぎると後段が過負荷になり、Noise Gate の判定も変わります。

  • Input Gain：Profile 全体の入力を増減。
背景ノイズ減衰声のない区間で定常ノイズを下げる

ファン、空調、部屋鳴りを滑らかな減衰で抑え、マイクを完全に閉じるより自然に保ちます。

歌配信での目安息声や弱い語尾を残したまま Maximum Reduction を少しずつ増やし、通常は Gate 前の穏やかな整理に使います。

注意点歌声と同時のノイズは分離できません。Threshold が高すぎる、または Close が速すぎると弱音が揺れたり消えたりします。

  • Maximum Reduction／Threshold：減衰量と開始レベル。
  • Open／Close：復帰と減衰の速度。
ノイズゲートフレーズ間でマイクを閉じる

Open と Close に別の閾値を使い、境界付近での細かな開閉を防ぎます。

歌配信での目安部屋のノイズを測り、息声の子音と長い語尾で試します。閾値だけを上げるより Hold と Release を適度に伸ばす方が自然です。

注意点歌唱中のキーボード音は除去できません。厳しすぎる設定は呼吸と語尾を切ります。Detector HPF は判定だけに作用します。

  • Open／Close Threshold：開く／閉じる境界。
  • Attack／Hold／Release：開き方、保持、閉じ方。
  • Closed Reduction／Detector HPF：閉時の減衰と低域判定除外。
コンプレッサー弱い声と強い声の差を整える

Threshold を超えたレベルの増加を Ratio で抑え、必要な分だけ Makeup で戻します。

歌配信での目安通常のピークで適度な Gain Reduction が出て戻るようにし、子音のアタックを残してから同じ音量で Bypass 比較します。

注意点Attack が速すぎると輪郭を失い、Release が短すぎるとポンピングします。Makeup を上げすぎるとノイズも増えます。

  • Threshold／Ratio：開始レベルと圧縮量。
  • Attack／Release：応答と復帰時間。
  • Makeup／Knee：補償と境界の滑らかさ。
イコライザー（EQ）不要帯域を除き、伴奏の中で声を見せる

6 バンドの Low Cut、Shelf、Bell、High Cut をグラフまたは数値で調整できます。

歌配信での目安不要な超低域を先に切り、広く小さな調整で濁りを減らし、存在感を少し足して音量だけに頼らず声を前へ出します。

注意点高 Q の大幅 Boost は共鳴とハウリングを強調します。固定の男女別レシピより歌手、マイク、部屋を実際に聴いてください。

  • Type／Frequency：形状と対象帯域。
  • Gain／Q：量と帯域幅。
  • Band Bypass：1 バンドだけ比較。
サチュレーション倍音、密度、意図的な荒さを加える

Warm Vocal、Rock Edge、Metal Bite は穏やかな密度から強い非線形の荒さまでを提供します。

歌配信での目安通常の歌唱は低い Drive／Mix から始め、ロックやスクリーム部分で段階的に増やし、Output Trim で同じ音量に合わせます。

注意点音量差を音質差と誤認しやすい効果です。過剰設定は歯擦音、ノイズ、子音のぼけを増やし、Limiter の余裕を減らします。

  • Type／Drive／Color：曲線、強さ、質感。
  • Mix／Output Trim：原音比と出力調整。
Air エンハンサー存在感、息遣い、高域の艶を加える

Mid Air は声の存在感、High Air はより高い帯域の息遣いと艶を強調します。

歌配信での目安少量の Mid Air で歌詞を通し、High Air は控えめに追加します。De-esser との組み合わせが大幅な高域 Boost より自然です。

注意点ヒス、部屋ノイズ、歯擦音も強調します。Output Trim で同じ音量にしてから明瞭さを判断します。

  • Mid Air／High Air：存在感と高域の艶。
  • Output Trim：Bypass との音量合わせ。
ディエッサー強い S／SH の歯擦音を抑える

指定した高域が目立つ瞬間だけ減衰し、声全体を常時暗くするものではありません。

歌配信での目安歯擦音が出やすい歌詞で、刺さりだけが減り子音が残る位置を探します。Air や明るい EQ の後に置くと追加された歯擦音も扱えます。

注意点Threshold が低すぎる、Maximum Reduction が大きすぎると舌足らずになります。中心周波数は歌手とマイクで異なります。

  • Frequency／Threshold：検出帯域と感度。
  • Maximum Reduction／Attack／Release：上限と時間応答。
ボイスチェンジャーPitch と Formant でキャラクターを作る

音高と声道サイズ感を別々に調整し、単純な移調だけより自然なキャラクター変化を作れます。

歌配信での目安小さな半音／Formant 変更から始めるか Mix で原音を戻し、実際の歌手に近い Vocal Range を選びます。

注意点大幅移調は人工的になり Profile latency も増える場合があります。匿名化や本人特定防止の機能ではありません。

  • Pitch／Formant：音高と声道サイズ感。
  • Mix／Vocal Range：原音比と解析補助。
ハーモニー曲の調に沿った実験的な補助声部を作る

曲の Key／mode と主旋律からダイアトニック 3 度またはオクターブを生成し、追跡信頼度が低い場合はフェードします。

歌配信での目安Key を確認し、低い Mix でサビやロングトーンを補います。Tone、Width、Humanize で主唱より後ろに配置します。

注意点Key の誤り、しゃくり、スクリーム、不安定な音程は追跡を乱します。実験的な合成声部を主唱より大きくしないでください。

  • Direction：上／下 3 度、上／下オクターブ。
  • Mix／Width：音量と左右展開。
  • Humanize／Tone／Tracking：揺らぎ、明るさ、信頼度条件。
ダブラーダブルトラックの厚みと広がりを作る

短い時間差とわずかなピッチ差を持つ 2 層で、明確なエコーではなく重ね録りを模擬します。

歌配信での目安ヴァースは低い Mix、サビは Switch で広げます。短い Delay、少ない Detune、中程度の Width が自然です。

注意点Delay／Mix が大きいと子音がぼけます。広すぎる設定は Mono で細くなるため、Stereo と Mono の両方を確認します。

  • Mix／Delay／Detune：音量、時間差、cent 差。
  • Width／Humanize／Tone：広がり、揺らぎ、明るさ。
ディレイSlap、KTV、リズムエコーを加える

直接音はそのまま残り、Time に従って反復します。短い値は Slap、長い値は明確なエコーになります。

歌配信での目安曲のテンポに Time を合わせ、Low／High Cut で主唱より細く暗い反復にし、Wet と Feedback は控えめにします。

注意点Feedback が高いと長く蓄積し、発振に近づきます。同じミリ秒値がすべてのテンポで拍に合うわけではありません。

  • Wet／Time／Feedback：音量、間隔、反復量。
  • Width／Low Cut／High Cut：左右差と帯域整理。
リバーブRoom、Plate、長い空間を作る

密な反射で奥行きを作り、Pre-delay が主唱と余韻を分け、Size、Decay、Damping が空間の性格を決めます。

歌配信での目安Pre-delay で子音を残してから Decay と Wet を調整します。トークは短く少なく、空気感のある歌唱は長めでも主唱を前に保ちます。

注意点実際の部屋が響く場合、長い Reverb は明瞭度を急激に下げます。Wet／Decay 過多は次の歌詞を隠します。

  • Wet／Pre-delay：量と出現までの時間。
  • Size／Decay／Damping：空間、長さ、明暗。
シマーリバーブ尾部に 1 オクターブ上の光彩を加える

余韻を高いオクターブへ移して Feedback し、Ducking で歌唱中は抑え、隙間で浮かせます。

歌配信での目安低い Wet、制御した Feedback、暗めの Tone、十分な Ducking から始め、Profile の標準状態を保存してサビを Switch します。

注意点明るい尾音は急速に蓄積します。Block Bypass、Profile の標準状態、曲中の一時 Switch は別の設定です。

  • Wet／Pre-delay／Decay：音量、開始、長さ。
  • Feedback／Tone／Ducking：蓄積、明るさ、主唱回避。
リミッターProfile 出力の突発ピークを止める

Profile Limiter と Output Final Limiter はステレオリンクの Lookahead 付き Sample-Peak Limiterで、True-Peak Limiter ではありません。Lookahead はサンプル点を先読みしますが、サンプル間ピークを再構成しません。

歌配信での目安Profile Limiter は偶発ピーク保護に使い、常時強く圧縮しません。正式 Mix は別の Final Limiter で保護し、標準 −1.0 dBFS ceiling がエンコード前の余裕を作ります。

注意点−1.0 dBFS Sample Peak でも AAC、リサンプリング、再構成後に −1.0 dBTP 未満とは限りません。dBTP 適合には True Peak 対応の後段ツールが必要です。

  • Input Gain／Ceiling：入力とサンプル点上限。
  • Release：ピーク後の復帰。
  • Lookahead：遅延を伴う先読みであり True Peak ではない。
