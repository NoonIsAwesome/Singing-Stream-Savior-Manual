# 시청자 신청곡과 스트리머 Studio

2.2.0.0부터 시청자가 웹에서 곡 목록을 보고 신청할 수 있습니다. 스트리머가 수락하면 **Reserve(재생 대기)**에 들어갑니다. **무료 기능이며, 악용으로 인한 서버 부하를 막기 위해 사용 전에 관리자 승인이 필요합니다.** 일반 로컬 재생에는 신청이 필요하지 않습니다.

## 처음 사용하기: 활성화 신청

1. 앱의 **시청자 신청곡**에서 사용 신청을 엽니다. 승인 전에는 온라인 기능 대신 신청 화면이 이 탭을 덮습니다.
2. 다른 사람과 중복되지 않는 스트리머 ID, 이름, 간단한 소개, 채널 URL, 이메일, Discord ID를 입력합니다. ID는 소문자 영문·숫자·하이픈·밑줄 3–50자로 정하고 채널 URL은 `https://`로 시작해야 합니다.
3. 이름은 **방송에서 쓰는 이름으로 적고 실명은 입력하지 마세요**. 소개는 짧아도 됩니다. 이메일과 Discord ID는 매니저나 회사의 연락처를 사용해도 됩니다. 신청 메시지는 선택 사항입니다. 쓸 말이 없다면 제작자를 칭찬해 주셔도 좋아요!
4. 신청 내용을 확인한 다음 제출합니다. 제출 후에는 바로 수정할 수 없으므로 연락처를 먼저 확인하세요.
5. 관리자 검토를 기다린 후 활성화 상태를 확인합니다. 승인되고 연결이 완료되면 기능이 표시됩니다. 검토 중에 중복 신청할 필요는 없습니다.

앱이 장치 인증 정보를 만들어 이 PC에 저장합니다. 로그인 비밀번호를 직접 만들거나 기록하고 입력할 필요가 없습니다. 다음 실행부터 저장된 정보로 자동 연결합니다.

## 곡 목록 공개와 회차 시작

1. 노래할 프로젝트를 열고 곡명, 아티스트와 분류를 확인합니다.
2. 시청자 신청곡 탭에서 공개 이름을 확인하고 필요하면 프로필 이미지와 회차 이름을 설정합니다. 회차 이름을 비우면 오늘 날짜를 사용합니다.
3. 온라인 신청곡을 시작하고 확인합니다. **현재 프로젝트**의 곡 목록을 웹에 공개하고 이번 회차를 만듭니다.
4. 앱에 표시된 시청자 링크를 복사해 방송 설명, 채팅이나 소셜 게시물에 공유합니다. 생성된 전체 링크를 사용하세요. 시청자는 S3S를 설치할 필요가 없습니다.
5. 링크를 열어 실제 시청자 화면을 확인합니다. 시청자는 곡을 검색·필터링하고 닉네임과 선택 메시지를 입력한 뒤 내용을 확인해 신청합니다.

공개되는 정보는 곡명, 아티스트, 길이, 장르, 언어, 사용자 재생 목록 분류와 신청 가능 상태 등입니다. 로컬 오디오 파일, 원본 경로, 가사나 보컬 효과 설정은 업로드하지 않습니다. 이 웹사이트는 신청곡 접수용이며 시청자가 PC의 반주를 듣는 플레이어가 아닙니다.

곡을 수정하거나 프로젝트를 바꾼 뒤에는 대상을 확인하고 곡 목록을 업데이트하세요. **로컬 수정만으로 웹에 반영되지는 않습니다.** 공개 곡 수와 마지막 업데이트 시간을 확인할 수 있습니다. OBS에 사용하는 로컬 곡 목록·가사 링크와 시청자 신청 링크는 다릅니다.

## 신청곡 검토와 재생 대기

새 신청곡이 오면 알림 수가 표시됩니다. 해당 탭이나 검토 대기 화면에서 곡명, 시청자와 메시지를 확인하고 이번 회차 전체, 대기, 수락, 거절로 필터링할 수 있습니다.

| 작업 또는 상태 | 결과 |
| --- | --- |
| 수락 | 기존 Reserve에 추가합니다. 즉시 재생되지는 않습니다. |
| 거절 | 검토 결과를 보관하고 Reserve에는 추가하지 않습니다. |
| Reserve | 수동으로 추가한 곡과 함께 드래그로 순서를 바꾸고 기존 재생 기능을 사용합니다. |
| 재생 중 / 부른 곡 | 재생 상태와 검토 결과는 별개입니다. 수락은 노래 완료를 뜻하지 않습니다. |

재생은 데스크톱 앱에서 이루어집니다. 현재 프로젝트의 음원을 사용할 수 있어야 합니다. 파일을 이동·삭제했거나 YouTube 음원을 사용할 수 없다면 먼저 음원을 수정하세요. 대기 목록 조작은 [라이브러리와 재생]({{ '/ko/guide.html' | relative_url }}#library-and-playback)을 참고하세요.

새 신청을 일시 중지하면 회차와 기존 기록은 유지되며 나중에 접수를 재개할 수 있습니다. 이번 회차를 끝내려면 온라인 신청곡을 닫고 확인하세요. 로컬 Reserve와 이번 신청 기록은 계속 사용할 수 있으며, 다음 회차에 다시 시작할 수 있습니다.

## 모바일 Studio 사용

데스크톱 앱에서 스트리머 관리 웹페이지를 열고 페이지 안내에 따라 브라우저나 휴대폰에서 Studio에 접속합니다. 조회할 회차를 선택해 신청을 검토하거나 기록을 확인하세요. Studio에는 스트리머 인증이 필요합니다. 비공개 접속 링크나 로그인된 세션은 본인만 사용하고, **시청자에게는 시청자 신청 링크를 공유하세요**.

모바일 Studio는 온라인 신청 관리용입니다. 곡은 PC에서 재생하며 휴대폰 오디오 플레이어가 되지는 않습니다. PC에 저장된 장치 인증 정보를 대체하지도 않습니다. 비공개 접속 링크가 만료되면 앱에서 다시 여세요. 브라우저 계정 로그인은 데스크톱 인증 정보의 백업이 아닙니다.

## 신청 상한과 인증 정보 백업

설정을 연 뒤에는 설정 접기 또는 신청 목록으로 돌아가기 버튼을 사용하세요.

- **미완료 신청 상한:** 시청자별 제한을 켜고 왼쪽 빼기, 가운데 숫자 입력, 오른쪽 더하기로 1–20곡을 지정한 뒤 저장합니다. 검토 대기 중인 곡과 수락했지만 아직 부르지 않은 곡이 포함됩니다.
- **스트리머 인증 정보 백업:** 암호화된 `.s3sidentity` 파일을 내보내며 8자 이상의 백업 비밀번호를 정합니다. 둘 다 안전하게 보관하세요. 이 비밀번호는 자동 저장되는 로그인 정보와 별도로 사용자가 정하는 백업용입니다.
- **인증 정보 복원:** PC를 바꾸거나 복구할 때 파일과 비밀번호로 복원합니다. 먼저 현재 온라인 회차를 종료하세요. 프로젝트 파일만으로는 복원할 수 없고 분실한 백업 비밀번호도 복구할 수 없습니다.

## 연결 또는 활성화 문제

| 화면 또는 상황 | 처리 방법 |
| --- | --- |
| 검토 중 / 승인되지 않음 | 활성화 상태를 확인하고 필요하면 관리자에게 문의하세요. 중복 신청은 필요하지 않습니다. |
| 다시 연결 중 | 연결 재시도와 로그인 인증 정보 갱신은 자동입니다. 몇 시간마다 직접 로그인할 필요가 없습니다. 네트워크 복구를 기다리거나 필요하면 다시 연결하세요. |
| 서버 점검 중 | 온라인 작업을 일시 차단하지만 저장된 인증 정보는 유지합니다. 점검 종료를 기다리거나 나중에 다시 연결하세요. |
| 서버를 일시적으로 사용할 수 없음 | 네트워크나 서비스 문제는 계정 삭제를 뜻하지 않습니다. 연결을 확인하고 재시도하세요. 점검 화면은 서버가 점검임을 명시한 경우에 표시합니다. |
| 장치 비활성화 / 신청곡 사용 정지 | 관리자가 스트리머 장치를 중지한 상태입니다. 활성화 상태를 확인하거나 관리자에게 문의하세요. 재설치로 제한이 풀리지는 않습니다. |
| 스트리머 계정 삭제됨 | 서버가 삭제를 확인하면 다시 신청할 수 있는 화면으로 돌아갑니다. 연결 오류만 있다면 먼저 연결 문제를 해결하세요. |
| 인증 정보 복원 필요 | 기존 암호화 백업을 복원하고 새 인증 정보로 반복 신청하지 마세요. |

**시청자 장치** 차단은 해당 시청자 브라우저의 신청을 제한하며 **스트리머 장치** 비활성화와 다릅니다. 연결, 점검이나 승인 제한은 클라우드 신청 기능에 적용됩니다. 로컬 라이브러리, Reserve와 플레이어는 계속 사용할 수 있지만 YouTube 같은 온라인 음원에는 여전히 네트워크가 필요합니다. 온라인 기록은 재연결 후 확인하고, 오프라인 동안의 오래된 웹 상태를 최신 결과로 판단하지 마세요.
