# 視聴者リクエストと配信者 Studio

2.2.0.0 から、視聴者が Web の曲目一覧を見てリクエストできるようになりました。配信者が承認してから **Reserve（再生待ち）**に入ります。**機能は無料です。不正利用によるサーバー負荷を防ぐため、利用前に申請と管理者の承認が必要です。** 通常のローカル再生には申請は不要です。

## 初回：利用を申請する

1. アプリの「視聴者リクエスト」で利用申請を開きます。承認前は、このタブのオンライン機能の代わりに申請画面が表示されます。
2. 配信者 ID、名前、自己紹介、チャンネル URL、メール、Discord ID を入力します。ID は他の配信者と重複しないものを指定し、半角小文字・数字・ハイフン・アンダースコアの 3～50 文字を使います。チャンネル URL は `https://` で始めてください。
3. 名前は**配信で使う名前にし、本名は入力しないでください**。紹介は簡単で構いません。メールと Discord ID はマネージャーや会社の連絡先でも構いません。申請メッセージは任意です。迷ったら作者を褒めていただいても！
4. 内容確認の画面で連絡先などを確認して送信します。送信後は直接編集できません。
5. 管理者の審査を待ち、「開通状況を確認」で結果を確認します。承認されて接続が完了すると機能が表示されます。審査中の再申請は不要です。

アプリが端末の認証情報を生成し、この PC に保存します。ログイン用パスワードの作成・メモ・入力は不要です。次回以降は保存済みの情報で自動接続します。

## 曲目一覧を公開して配信回を開始する

1. 歌う予定のプロジェクトを開き、曲名・アーティスト・分類を確認します。
2. 視聴者リクエストの公開名を確認し、必要に応じて画像と配信回の名前を設定します。配信回の名前が空欄なら当日の日付を使います。
3. オンラインリクエストの開始を押して確認します。**現在のプロジェクト**の曲目一覧を公開し、今回のリクエスト受付を開始します。
4. アプリに表示された視聴者用リンクをコピーし、配信概要欄やチャットなどで共有します。生成されたリンク全体を共有してください。視聴者に S3S のインストールは不要です。
5. リンクを開き、実際の視聴者ページを確認します。視聴者は曲を検索・絞り込みし、ニックネームと任意のメッセージを入力して、確認後にリクエストします。

公開するのは曲名、アーティスト、長さ、ジャンル、言語、独自プレイリスト分類、リクエスト可否などです。ローカル音源、ファイルパス、歌詞、ボーカルエフェクト設定はアップロードしません。このサイトはリクエスト受付用であり、視聴者が PC の伴奏を聴くためのプレーヤーではありません。

曲の編集やプロジェクト変更後は、対象を確認して曲目一覧を更新してください。**ローカルで編集しただけでは Web に反映されません。** 公開曲数と最終更新時刻を確認できます。OBS 用のローカルセットリスト・歌詞リンクと、視聴者用リンクは別のものです。

## 承認して再生待ちに入れる

新しいリクエストが届くと通知数が表示されます。このタブや審査待ちの画面で曲名・視聴者・メッセージを確認し、今回の全件、審査待ち、承認済み、拒否済みで絞り込めます。

| 操作・状態 | 動作 |
| --- | --- |
| 承認 | 既存の Reserve に追加します。すぐには再生しません。 |
| 拒否 | 審査結果を残し、Reserve には追加しません。 |
| Reserve | 手動で追加した曲と一緒に、通常のドラッグ並べ替え・再生操作を使えます。 |
| 再生中・歌唱済み | 再生状況と承認結果は別です。承認は歌唱完了を意味しません。 |

再生するのは PC のアプリです。ファイルの移動・削除や YouTube 音源の利用不可がある場合、先に音源を修正してください。基本操作は[ライブラリと再生]({{ '/ja/guide.html' | relative_url }}#library-and-playback)を参照してください。

新規受付の一時停止では配信回と既存の記録が残り、後で受付を再開できます。今回を終了するときはオンラインリクエストを閉じ、確認します。ローカルの Reserve と今回の記録は引き続き利用でき、次回は改めて受付を開始します。

## スマートフォンの Studio を使う

アプリから配信者用管理ページを開き、ページの案内に従ってブラウザーやスマートフォンで Studio にアクセスします。対象の配信回を選び、審査や記録の確認を行います。Studio には配信者の認証が必要です。専用の非公開リンクやログイン済みセッションは自分だけで使い、**視聴者には視聴者用リンクを共有してください**。

スマートフォンの Studio はオンライン管理用です。曲は PC で再生し、スマートフォンの音楽プレーヤーにはなりません。PC に保存された端末の認証情報の代わりにもなりません。専用リンクの期限が切れた場合はアプリから開き直してください。ブラウザーのアカウントログインだけでは、PC の認証情報はバックアップされません。

## 上限と認証情報のバックアップ

設定を開き、戻るときは設定を折りたたむボタン、またはリクエスト一覧に戻るボタンを使います。

- **未完了リクエストの上限**：視聴者ごとの制限を有効にし、左のマイナス、中央の数値入力、右のプラスで 1～20 曲を指定して保存します。審査待ちと、承認済みでまだ歌っていないリクエストが対象です。
- **認証情報のバックアップ**：暗号化された `.s3sidentity` ファイルを書き出し、8 文字以上のバックアップ用パスワードを設定します。両方を安全に保管してください。これは自動保存されるログイン情報とは別の、自分で設定するパスワードです。
- **認証情報の復元**：PC の変更や復旧時にはファイルとパスワードで復元します。先にオンラインの配信回を終了してください。プロジェクトファイルだけでは復元できず、紛失したバックアップ用パスワードも復旧できません。

## 接続・利用状況のトラブル

| 表示・状況 | 対処 |
| --- | --- |
| 審査待ち・申請が承認されなかった | 開通状況を確認し、必要なら管理者に連絡します。申請の繰り返しは不要です。 |
| 再接続中 | 接続とログイン情報の更新は自動です。数時間ごとの手動ログインは不要です。ネットワークの復旧を待ち、必要なら再接続します。 |
| サーバーメンテナンス中 | オンライン操作を一時停止しますが、認証情報は保持します。終了を待つか、後で接続を再試行します。 |
| サーバーが一時的に利用不可 | ネットワークやサービスの問題であり、アカウント削除を意味しません。接続を確認して再試行します。メンテナンスの表示はサーバーが明示した場合に限ります。 |
| 端末の無効化・利用停止 | 配信者端末が管理者によって停止されています。開通状況を確認するか、管理者に連絡してください。再インストールでは解除されません。 |
| 配信者アカウントが削除された | サーバーが削除を確認すると、再申請できる画面に戻ります。接続エラーだけの場合は先に接続を確認してください。 |
| 認証情報の復元が必要 | 既存の暗号化バックアップを復元し、新しい情報で申請を繰り返さないでください。 |

**視聴者の端末**のブロックは、その視聴者ブラウザーのリクエストを制限するもので、**配信者端末**の利用停止とは異なります。接続・メンテナンス・承認による制限はクラウドのリクエスト機能に適用され、ローカルのライブラリ、Reserve、プレーヤーは使えます。ただし、YouTube などのオンライン音源には引き続きネットワークが必要です。オンライン記録は再接続後に確認し、オフライン中の古い表示を最新の結果と判断しないでください。
